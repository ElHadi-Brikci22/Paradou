1. OBJECTIF & VISION DU SYSTÈME
--------------------------------------------------------------------------------
L'objectif est de transformer le système actuel en une solution de caisse 
professionnelle commercialisable auprès de pressings clients :
  - Le serveur central (Laravel + MySQL) est hébergé sur le Web (Cloud / VPS).
  - La caisse fonctionne via une application Desktop native propre (Electron).
  - La caisse opère en mode DUAL :
      * En ligne : Transactions synchronisées en temps réel.
      * Hors ligne : En cas de coupure d'Internet ou de panne réseau, la caisse 
        continue à encaisser, enregistrer les commandes et imprimer les tickets 
        instantanément sans aucun ralentissement ni blocage.
      * Reconnexion : Synchronisation automatique et transparente des commandes 
        locales vers le Cloud dès le rétablissement de la connexion.

--------------------------------------------------------------------------------
2. ORGANISATION GIT & REPOSITORIES (APPROCHE MULTI-REPO PROFESSIONNELLE)
--------------------------------------------------------------------------------
Pour isoler les responsabilités et ne jamais déstabiliser le code existant :

  REPO 1 : [Paradou] (Le dépôt actuel)
  ------------------------------------
  Rôle : Backend API Cloud & Dashboard Web Administrateur.
  Technos : Laravel 11, PHP 8.3+, MySQL.
  Branches :
    - main    : Version de production déployée sur le serveur Cloud.
    - develop : Branche d'intégration des nouvelles fonctionnalités API.
    - feat/*  : Branches de travail (ex: feat/pos-api).

  REPO 2 : [Paradou-POS-Desktop] (Nouveau dépôt à créer)
  ------------------------------------------------------
  Rôle : Application Caisse Tactile de Comptoir (Installable sur PC client).
  Technos : Electron, Node.js, Frontend Vue/Vite (ou Vanilla JS optimisé), 
            IndexedDB / SQLite local, Pilote USB/Network ESC/POS.
  Branches :
    - main    : Releases stables des installateurs Windows (Setup.exe).
    - develop : Développement et intégration continue des modules Desktop.
